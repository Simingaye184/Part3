
VOGUE STUDIO — README
Tailor-Made For Every Mbokodo

1. WHAT IS THIS PROJECT?
Vogue Studio is a boutique fashion studio website based in Amanzimtoti, KZN, South Africa. The site is built with pure HTML, CSS and vanilla JavaScript — no frameworks. Dark theme with gold accent #d4af37.

Tagline: "Custom fits. Quality fabric. Confidence in every stitch."

2. THE FEATURED LOOK (svv.jpeg)
The image you uploaded is your hero piece:

6. HOW TO RUN

Put all files in one folder
Rename Index.html to index.html (lowercase) for live servers
Double-click index.html OR run: python -m http.server 8000
Open http://localhost:8000
Test contact form — it will redirect to WhatsApp
